1500小助手

一个纯前端的本地题库搜索工具，部署在 GitHub Pages 上，通过网址访问即可使用。支持模糊搜索、同音字识别、题型筛选和错题反馈。

---

✨ 功能特性

功能 说明
🔍 智能搜索 支持单关键词、多关键词（空格分隔），标点符号可省略
🎯 题型筛选 全部 / 单选 / 多选 / 判断
🔊 同音识别 输入错别字也能搜到（如「地贴」→「地铁」）
📝 选项匹配 直接粘选项里的一句话也能搜到对应题目
🚫 自动去重 题库内容完全相同的题只显示一条
📢 错题反馈 一键复制反馈内容，粘贴发给维护人
📅 更新日期 页面底部显示题库最近更新时间
🔒 访问密码 防止无关人员访问

---

📁 文件结构

```
仓库根目录/
├── index.html    ← 主程序（界面 + 逻辑）
├── bank.js       ← 题库数据（含更新日期）
└── README.md     ← 本文件
```

两个文件必须放在同一目录下，缺一不可。

---

🚀 使用方法（普通用户）

1. 打开访问网址（由维护人提供）
2. 输入访问密码 → 进入
3. 在搜索框输入关键词 → 实时显示匹配结果
4. 找到题目后，答案就在卡片底部

搜索技巧

场景 输入示例
搜题干关键词 两相邻车站
多关键词（都要命中） TVM 发售 无效票
搜选项内容 行政收入
只想看多选题 先输关键词，再选「多选」

反馈错题

1. 发现某道题答案错了 → 点卡片右下角「📢 反馈」
2. 在弹窗里描述问题（可选，比如「答案应该是 B」）
3. 点「📋 复制并关闭」→ 内容自动复制
4. 到微信里粘贴发给维护人

🛠️ 部署方式（维护人）

首次部署

1. 在 GitHub 新建一个仓库（Public）
2. 上传 index.html 和 bank.js 到仓库根目录
3. 进入 Settings → Pages
4. Source 选择 Deploy from a branch，Branch 选 main，目录选 / (root)
5. 保存后等 1 分钟
6. 访问 https://你的用户名.github.io/仓库名/

---

🔄 更新题库

方式 A：GitHub 在线编辑（推荐，最快）

1. 打开 GitHub 上的 bank.js
2. 点右上角铅笔图标 ✏️ 进入编辑
3. 修改内容：
   · 顶部第一行的日期：// 更新日期：2026-09-28
   · 以及 updateDate: "2026-09-28"（两处都要改）
   · 找到对应题目（每题一行，用 Ctrl+F 搜索关键词）
4. 底部点 Commit changes
5. 等 30 秒自动生效，index.html 完全不用动

方式 B：重新生成（题库大改时）

在本地改好 bank.json 后，运行生成脚本 → 上传新的 bank.js。

❓ 常见问题

Q：页面显示"题库加载失败，请刷新页面重试"

说明 bank.js 没加载成功。检查：

· 两个文件是否在同一目录
· 文件名是否严格是 bank.js（不是 bank.js.txt）
· bank.js 内容是否完整（不能被截断）

Q：改了 bank.js 后页面没变化

可能是浏览器缓存。试试：

· 强制刷新：Ctrl + Shift + R（电脑）/ 下拉刷新（手机）
· 或在网址后面加 ?v=2 再访问

Q：搜索不到我想找的题

按顺序排查：

1. 换个关键词，尽量用题干里最独特的词
2. 试试只输入核心名词（不要整段话）
3. 题目可能不在题库里，请联系维护人补充

Q：同音字搜索没反应

· 首次加载需要下载拼音库（约 200KB），等几秒
· 如果网络问题导致 CDN 加载失败，会自动切换备用源
· 实在不行会直接跳过同音搜索，只显示普通结果

Q：为什么密码在源码里能看到？

这是纯静态页面，没有服务器。密码只是防误入，不是真正的安全防护。请不要把网址公开分享。

🔐 安全提示

· 本工具的所有数据都在浏览器本地处理，不上传任何信息
· 访问密码明文写在 index.html 里，懂技术的人查看源码能看到
· 请勿将网址公开传播，仅限内部小范围使用

---

📝 技术说明

· 纯静态：无后端、无数据库、无第三方服务（除拼音库 CDN）
· 搜索算法：基于 Dice 系数的模糊匹配 + 多关键词 AND 逻辑
· 拼音识别：调用 pinyin-pro 库做同音兜底
· 适配：兼容 PC 浏览器、iOS Safari、微信内置浏览器、Android 浏览器
